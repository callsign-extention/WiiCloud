# WiiCloud
With Wii Cloud, you can easily backup all of your saves to the cloud, this means that you will no longer run out of storage by grinding your game, instead you can have your save automatically connected to the cloud so you do not remove it and have to start over, of course this is not free (for bigger drives) you will have a restrain on how many saves you can hold, but that is about it. Happy Gaming!
Steps:
Install WiiCloud.zip
Extract It
Plant It On A USB Hard Drive Or SD Card (in the Apps Folder)
Open Homebrew Channel
Enjoy!
